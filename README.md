# Gender Composition Across Doctoral Cohorts in US Transportation Engineering Faculty

Replication files for Andrew J. Bae's Findings manuscript. The public audit records omit individual profile URLs, excerpts, and corroborating source links. The reviewer attachment contains the source evidence. The roster uses numeric IDs, and combinations of remaining attributes may identify individuals.

Run from the repository directory with Python 3.9.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python audit_selection.py
.venv/bin/python analyze.py
```

See DATA-DICTIONARY.txt for variable definitions and results/ for the generated tables. The analysis concerns a January 2026 roster.
